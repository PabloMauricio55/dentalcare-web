# Módulos de dominio

Cada módulo contiene sus propios `models`, `dtos`, `adapters`, `services`, `components` y `mocks`. Las piezas reutilizables entre dominios viven en `src/shared`.

- `auth`
- `public-catalog`
- `patients`
- `appointments`
- `medical-history`
- `clinical-records`
- `treatments`
- `billing`
- `inventory`
- `sterilization`
- `reports`
- `settings`
