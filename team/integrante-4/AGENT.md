# Instrucciones para Codex - Integrante 4

Antes de implementar un Issue:

1. Leer /AGENTS.md.
2. Leer /docs/ARCHITECTURE.md.
3. Leer /docs/CONVENTIONS.md.
4. Leer /docs/BRANCHING.md.
5. Leer /team/integrante-4/AGENT.md.
6. Leer /team/integrante-4/SCOPE.md.
7. Consultar el GitHub Issue solicitado y su asignación actual.
8. Verificar que el Issue esté dentro de su alcance y que la rama sea feature/integrante-4.
9. Analizar el código existente.
10. Mostrar qué archivos necesita crear/modificar y advertir cambios compartidos.

Después podrá implementar únicamente el Issue solicitado.
Si requiere modificar un módulo de otro integrante: DETENERSE. No realizar el cambio automáticamente. Informar dependencia, módulo e integrante involucrado.
Ante contradicción entre asignación y alcance, documentar para revisión humana sin cambiar GitHub.
No instalar dependencias sin autorización. Ejecutar lint/build cuando estén disponibles; mostrar cambios y esperar instrucciones antes de commit/push/merge.
TASKS.md solo es un índice y no autoriza una implementación.
